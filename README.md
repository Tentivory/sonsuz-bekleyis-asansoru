# Sonsuz Bekleyiş Asansörü

## Resmi Dokümantasyon

Bu proje, insanlığın en kadim sorunlarından biri olan "Asansör ne zaman gelecek?" sorusuna bilimsel ve felsefi bir çözüm sunmaktadır. Cevap: Asla.

### Neden Bu Proje?

- Asansörün gelmesi beklenirken yaşanan varoluşsal krizleri simüle eder.
- Her basışta "Geliyor..." der ama asla gelmez.
- Bekleme süresi her seferinde katlanarak artar, tıpkı gerçek hayattaki gibi.

### Kullanım

```bash
python asansor.py
```

Ekranda sonsuz bir bekleyiş göreceksiniz. Ctrl+C ile kaçabilirsiniz ama ruhunuz kaçamaz.

### Bilimsel Temel

Heisenberg'in belirsizlik ilkesine göre, asansörün hem konumu hem de geliş zamanı aynı anda bilinemez. Bu simülatör bunu kanıtlar.

### Katkıda Bulunma

Lütfen pull request açmayın. Asansör zaten yeterince bekliyor.
